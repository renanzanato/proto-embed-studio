# LBS Prototype Showcase

Crie uma página chamada "Protótipo LBS" e incorpore nela o seguinte protótipo do Figma.

O protótipo deve:

- ocupar 100% da largura disponível

- ter altura mínima de 800px

- ser responsivo

- não gerar rolagem horizontal

- manter bordas arredondadas

- funcionar corretamente em desktop e mobile
